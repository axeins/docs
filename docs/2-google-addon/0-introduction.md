# Introduction

The **AX1 Add-on** lets you seamlessly access accounting data in Google Sheets with powerful synchronization:

- **One-Time Installation**: Install once, use across **any Google Sheet** in your workspace.
- **Sheet-Specific Configurations**:
  - Data imports and settings are saved **per spreadsheet** (not per user).
  - All users with edit access will see the same configurations.
- **Real-Time Collaboration**: Changes sync automatically for everyone with sheet access.
- **Flexible Usage**: Fetch different data types (accounts, entries, cost centers) with one click.
