# Settings

### **Change Language**

1. Go to **Extensions > AX1 > Settings**.
2. Select your preferred language (`English` or `German`).

   ![Settings](/img/ax1-settings.png)

### **Enable Logging (Optional)**

To track all data imports:

1. In **Settings**, enable **Logging**.
2. Enter a log file name (e.g., `AX1_Import_Logs`).

Logs will record:

- Timestamp
- Sheet name
- Success/Failure status
- Errors (if any)
